JSG CI 색상 가이드
2026.09.18

브랜드의 생각
이성에 근거한 대담한 비전.
두 파랑은 합리적인 판단과 과감한 실행이 함께하는 JSG를 표현한다.
아래 의미는 JSG의 색상 사용 기준이며, IBM이 정한 의미는 아니다.

1. 기본 색상
밝은 파랑: #226CF5 / RGB 34, 108, 245
도전과 실행. 새로운 가능성을 발견하고, 확신을 행동으로 옮긴다.
심벌의 왼쪽 두 조각, 주요 강조와 링크에 사용한다.

짙은 파랑: #001D6C / RGB 0, 29, 108
합리적 판단과 책임. 근거를 검토하고, 맡겨진 자본을 신중하게 운용한다.
심벌의 오른쪽 두 조각, 주요 제목과 안정감이 필요한 배경에 사용한다.
투자 성과나 원금 보장을 뜻하지 않는다.

흰색: #FFFFFF
명료함과 투명성. 내용을 읽기 쉽게 하고 두 파랑 사이에 여유를 만든다.
기본 배경과 심벌의 분할 틈에 사용한다.

2. 보조 색상
밝은 회색 #F4F4F4: 본문을 차분하게 받쳐 주는 배경.
본문 검정 #000000: 정보를 분명하게 전달하는 글자.
사이안 #04F8FD: 발견과 과학적 호기심. 필요할 때만 소량 사용한다.
사이안은 심벌의 기본 파랑을 대신하지 않는다.
빨강·노랑·초록은 오류·주의·완료 등 상태 안내에 사용한다.

3. 쉬운 사용 원칙
흰색과 회색을 바탕으로 두 파랑을 반복해 사용한다.
밝은 파랑은 행동과 강조, 짙은 파랑은 신뢰와 판단의 역할을 유지한다.
파란 배경에는 흰 글자를 쓴다. 두 파랑을 글자와 배경으로 겹치지 않는다.
사이안 배경에는 검정이나 짙은 파랑 글자를 쓴다.
상태 안내에는 색상과 함께 글자나 아이콘을 넣는다.
로고에는 그라데이션, 입체 효과, 그림자, 임의의 테두리를 넣지 않는다.
인쇄 색상은 종이와 출력 방식에 따라 달라지므로 실물 교정으로 확인한다.

4. 심벌 형태와 이번 복원본
원형 윤곽을 유지하고 가로·세로를 같은 비율로 확대·축소한다.
왼쪽으로 휜 세로 틈과 오른쪽으로 완만하게 올라가는 가로 틈이
심벌을 네 조각으로 나눈다. 두 틈의 교차점은 중심보다 왼쪽 아래다.
틈의 폭은 사진상 지름의 약 5~6%, 가로 틈의 기울기는 약 7도다.
이 수치는 사진에서 읽은 근사치이며 원본 제작 도면의 치수가 아니다.
흰 틈과 주변 여백을 유지하고, 기본적으로 흰 배경에서 사용한다.

복원 이미지: assets/shared/jsg-emblem-ci-20260918.png
투명 배경: assets/shared/jsg-emblem-ci-20260918-transparent.png
투명 버전은 바깥 배경과 조각 사이의 틈이 모두 투명하다.
로고가 선명하게 보이는 밝은 단색 배경에 사용한다.
참조 사진: jsg-logo-photo.jpg
사진의 형상을 참고해 이미지 생성 도구로 복원한 흰 배경 PNG다.
생성 이미지의 개별 픽셀에는 기준 HEX와 미세한 차이가 있을 수 있다.
향후 정확한 인쇄·벡터 제작 시에는 위 기본 HEX를 기준으로 한다.
