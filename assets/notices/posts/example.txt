공지사항 추가 방법 (TXT 본문 + JSON 목록)

1) 새 ID 정하기
- ID는 6자리 숫자 문자열입니다. 예) 000006
- 파일명도 동일하게 만듭니다. 예) assets/notices/posts/000006.txt

2) 본문 작성하기
- 000006.txt에 내용을 “일반 텍스트”로 작성합니다.
- 줄바꿈은 그대로 화면에 표시됩니다.
- HTML 태그(<p>, <br> 등)는 쓰지 마세요. 그대로 글자로 보입니다.

3) 첨부파일이 있으면 attachments 폴더에 넣기
- 파일을 assets/notices/attachments/ 에 저장합니다.
- 파일명이 링크로 그대로 표시됩니다(대/소문자 포함).

4) 목록 파일에 메타데이터 추가하기
- assets/notices/notices.json 에 아래 형식으로 항목을 추가합니다.
  (날짜는 YYYY-MM-DD, ID는 문자열, 새 글이 위로 오도록 date 기준 정렬됩니다.)

{
  "id": "000006",
  "title": "공지 제목",
  "date": "2025-12-18",
  "isImportant": false,
  "category": "일반",
  "attachments": ["파일명.pdf"]
}

- 첨부파일이 없으면 "attachments": [] 로 두거나, attachments 필드를 생략해도 됩니다.

5) 배포 후 캐시 갱신(권장)
- 공지/첨부가 바뀌면 assets/notices/notices-manifest.json 의 assetVersion을 오늘 날짜로 업데이트하면 반영이 안정적입니다.
